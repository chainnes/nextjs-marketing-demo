FAQ

Questions, answered

What is Northwind Signal?+

Northwind Signal is a fictional AI marketing platform used in this concept demo. It combines an industry analysis agent, a B2B social media manager and an AI content studio.

Does AI content get published automatically?+

No. In this concept every draft goes through human review and approval before it is scheduled or published.

How would payments work?+

Pricing buttons are placeholders. In production they would open Stripe Checkout sessions created by a server route; in this static demo Stripe is not connected.

Where is form data stored?+

The contact form validates in the browser. The README documents how a server action would insert submissions into a Supabase Postgres table with row-level security.

Is this a real company?+

No. Brand, pricing, metrics and blog posts are sample content created for a portfolio demo by Charlene Cordero.
